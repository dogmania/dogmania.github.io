  4. 요청할 삭제 범위

삭제 범위는 다음 중에서 선택할 수 있습니다.

  • 기존 일단 서비스 계정과 서버 데이터 삭제
  • 클라우드 백업 계정과 백업 데이터 삭제
  • 기존 계정과 클라우드 백업 계정 모두 삭제
  • 계정은 유지하고 클라우드 백업 데이터만 삭제

계정 도용을 방지하기 위해 요청을 보낸 이메일과 계정 정보를 확인하는 절차가 진행될 수 있습니다. 비밀번호, OAuth 토큰 또는 인증 코드는 절대로 이메일로 보내지 마세요.

본인 확인이 완료된 날로부터 7일 이내에 삭제 요청을 처리하고 결과를 이메일로 안내합니다.

2. 앱에서 직접 삭제하기

앱을 사용할 수 있는 경우 설정 화면에서도 직접 삭제할 수 있습니다.

기존 일단 계정 삭제

마이페이지 → 설정 → 회원 탈퇴

기존 일단 서버 계정과 계정에 연결된 서버 데이터를 삭제합니다.

클라우드 백업 계정 삭제

마이페이지 → 설정 → 클라우드 백업 → 백업 계정 삭제

다음 데이터가 삭제됩니다.

  • 클라우드 백업용 OAuth 계정
  • Supabase에 저장된 백업 파일
  • 백업 파일의 생성 시각, 크기, 체크섬 등 백업 메타데이터

백업 데이터만 삭제

마이페이지 → 설정 → 클라우드 백업 → 백업 데이터 삭제

클라우드 백업 파일과 백업 메타데이터만 삭제합니다. 클라우드 백업 계정은 유지됩니다.

3. 삭제되는 데이터

계정 전체 삭제를 요청하면 확인된 삭제 범위에 따라 다음 데이터가 삭제됩니다.

  • 일단 사용자 계정
  • 소셜 로그인 제공자와 연결된 계정 식별 정보
  • 기존 서버에 저장된 할 일, 카테고리, 일정 및 기록 데이터
  • 클라우드 백업용 Supabase 인증 계정
  • 클라우드 백업 파일
  • 백업 생성 시각, 파일 크기 및 체크섬 등의 백업 메타데이터

카카오 또는 Apple 계정 자체는 삭제되지 않습니다. 일단에 연결된 계정과 데이터만 삭제됩니다.

또한 카카오나 Apple 계정을 탈퇴하는 것만으로 일단에 저장된 계정과 백업 데이터가 자동으로 삭제되지는 않을 수 있습니다. 일단 앱 또는 본 페이지의 이메일을 통해 별도로 삭제를 요청해 주세요.

4. 기기에 저장된 로컬 데이터

일단의 할 일, 카테고리 및 기록은 사용자의 기기 내부에도 저장될 수 있습니다.

기기에만 저장된 데이터는 개발자가 원격으로 접근하거나 삭제할 수 없습니다. 다음 방법으로 사용자가 직접 삭제할 수 있습니다.

  • 일단 앱 삭제
  • 운영체제 설정에서 일단 앱의 저장 공간 또는 앱 데이터 삭제

클라우드 계정이나 백업 데이터를 삭제해도 현재 기기에 저장된 로컬 데이터가 자동으로 삭제되지는 않습니다.

5. 별도로 보존될 수 있는 데이터

계정 및 백업 데이터는 삭제 완료 후 별도로 보존하지 않습니다.

다만, 사용자가 개발자에게 의견 보내기 기능을 통해 직접 제출한 다음 정보는 문의 처리와 서비스 악용 방지를 위해 접수일로부터 최대 1년간 보관될 수 있습니다.

  • 의견 내용
  • 사용자가 선택적으로 입력한 연락처
  • 앱 버전 및 사용 플랫폼
  • 접수 및 처리 상태
  • 중복 요청 및 악용 방지를 위한 비식별 처리 정보

위 의견 데이터의 삭제도 원하는 경우 이메일 삭제 요청에 함께 적어주세요. 본인과 연결된 데이터임을 확인할 수 있는 범위에서 함께 삭제합니다.

법령에 따라 일정 기간 보관해야 하는 정보가 발생하는 경우에는 해당 법령에서 정한 기간만 보관하고, 보관 기간이 종료되면 지체 없이 삭제합니다.

6. 계정 삭제와 앱 재설치

삭제된 계정과 클라우드 백업 데이터는 복구할 수 없습니다.

계정 삭제 후 앱을 다시 설치하거나 동일한 카카오 또는 Apple 계정으로 로그인하면 새로운 계정으로 처리될 수 있으며, 이전에 삭제한 백업은 복원할 수 없습니다.
